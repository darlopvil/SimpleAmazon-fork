SimpleAmazon (BETA)

A simple frontend for searching amazon.com

The page you are trying to access can't yet be processed by SimpleAmazon

You can check if the handling for this is already being worked on, or maybe you want to submit an Issue to request it yourself on our Codeberg Repository

This is a frontend for searching amazon that allows you to search for your amazon articles without the requirement for JavaScript and without being traced by amazon itself.

All images on this site are proxied so you don't have to ping amazon yourself, but the results all redirect to amazon itself because product pages aren't implement yet.
